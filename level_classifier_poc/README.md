# HH Level Classifier PoC (junior/middle/senior)

PoC: по резюме hh.ru автоматически предсказываем уровень разработчика: junior / middle / senior.

## Что делает
1) Фильтрует резюме IT-разработчиков по названию и/или навыкам.
2) Размечает целевую переменную y (junior/middle/senior) по названию должности и/или опыту.
3) Строит график баланса классов.
4) Обучает классификатор (TF-IDF текст + табличные признаки).
5) Выводит classification report и сохраняет артефакты.
